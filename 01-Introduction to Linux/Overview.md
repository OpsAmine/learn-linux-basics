# Overview


## What is Linux?

Linux, also called GNU/Linux, is a free open-source operating system (OS), much like Windows or Apple macOS. It is based on Unix that runs on computers, servers, mobile phones and a lot more type of devices. Unlike operating systems like Windows or macOS which are proprietary and not publicly available, Linux is built to be publicly available for anyone in the world to read, modify, and distribute. Am sure all who're reading this have met Linux, the OS with the penguing logo.

## History

### Unix and GNU (1960s -- 1980s)

**Unix (1969):** Developed at Bell Labs by Ken Thompson and Dennis Ritchie, Unix set the foundation for multi-user, portable operating systems. However, it was proprietary and expensive.

**The GNU Project (1983):** Richard Stallman launched GNU to build a free, Unix-like operating system utilities and the GNU General Public Licznse (GPL), though a core piece which is the kernel was missing.

**MINIX (1937):** Andrew Tanenbaum created MINIX, a small, UNIX-like system for educational purposes, which inspired Linux Torvalds.

### Birth of the Kernel (1991):

While studying computer science at the University of Helsinki, Linus Torvalds grew frustrated with the limits of MINIX and wanted a free OS kernel. Then he announced his project in August 25th, 1991.

In September 17th of the year 1991, version 0.01 of the Linux kernel was officially released to the public. By combining Torvalds' kernel with Richard Stallman's GNU tools and utilities, a complete, free operating system came together.

## Linux's Key Features

- **Open Source:** Linux source code is publicly available under open-source licenses, primarily the GNU General Public License (GPL). This allows developers to inspect, modify, and distribute the source code according to their needs.

- **Security:** Linux provides built-in security mechanisms, including user and group permissions, privilege separation, access control mechanisms (DAC), and security frameworks such as SELinux and AppArmor.

- **Stability and Reliability:** Linux is known for its stability and ability to operate continuously for extended periods, making it a popular choice for enterprise servers, cloud infrastructure, and mission-critical applications.

- **Portability and Hardware Support:** Linux supports a wide range of hardware architectures, from embedded systems and IoT devices to desktop computers, enterprise servers, and cloud platforms.

- **Customizability:** Linux offers extensive customization options, allowing administrators and users to configure the kernel, system services, desktop environments, software packages, and overall system behavior according to their requirements.

- **Multitasking and Multi-user:** Linux can execute multiple processes and background services concurrently through efficient CPU and memory management. It Also allows multiple users to access and work on the same system simultaneously, with each user having separate accounts, permissions, and resources.


## Why You Should Use Linux

- **Cost effective:** The operating system and thousands of apps are free under open-source licenses, saving users expensive software and OS upgrade fees.

- **Privacy and Control:** Linux does not track your behavior, display forced advertisements, or bundle aggressive telemetry the way modern commercial operating systems often do. You own your data.

- **Old Hardware Support:** Linux is lightweight and runs smoothly on low-spec or older computers, extending their usable life for years.

- **Community:** The Linux community is huge, and keeps growing each year, with being active, providing documentations, forums, and user groups across multiple platforms where both new users to Linux and advanced ones can find support and guidance.


## Linux Distributions

A Linux distribution represent an operating system on top of the Linux kernel, bundled with the essential softwares, tools, and package managers to serve different type of users (Enterprises, Developers, Cybersecurity Professionals, General Users, etc.). Some of the popular distributions are as following:

### Popular Linux Distributions

- **Ubuntu:** A user-friendly distribution widely adopted for desktop environments, servers, and cloud infrastructure.
- **Red Hat Enterprise Linux (RHEL):** An enterprise-focused distribution known for its stability, security, and commercial support.
- **CentOS:** A distribution historically derived from RHEL, commonly used in enterprise environments. CentOS Stream now serves as the upstream development platform for RHEL.
- **Debian:** A community-driven distribution recognized for its stability, reliability, and extensive software repositories.
- **Arch Linux:** A lightweight, rolling-release distribution designed for advanced users who require extensive control and customization.
- **Fedora:** A community-driven distribution that emphasizes innovation and the adoption of emerging technologies.
- **Raspberry Pi OS:** A lightweight distribution optimized for Raspberry Pi hardware and embedded computing projects.
